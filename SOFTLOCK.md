# Softlock report

Generated by `npm run verify:softlock`. CI regenerates this file and fails
if it differs from the committed copy, so it cannot drift from the game.

## What was searched

Every state the game can be put into, where a state is *what Summer has
permanently changed*: which chests are open, which doors are open, which
bosses are down. Her position is not part of the state, because from any
state she can walk anywhere the reachability model says she can.

Reachability is modelled from the room data and the rules in SPEC.md -
four-way steps, jumps over runs of pit tiles as far as the current jump
carries, raised ledges that need the Gale Sandals - rather than by running
the movement code. It is a second opinion, not an echo.

every interleaving of collecting and spending them, including spending keys
on the optional door first.

## 3. Pits cannot trap her

For every distinct movement configuration, the tile graph is walked forwards
from Cinderhome and backwards from Cinderhome. Any tile reachable forwards
but not backwards would be somewhere a jump could strand her.

**One-way tiles across all 332 configurations: 0.**

This holds because falling into a pit is not a death and not a trap: Summer
loses half a heart and is replaced on the last tile she stood on safely, so
a missed jump costs health and never position. There is also no three-tile
pit anywhere in the game, so the Gale Sandals are never insufficient for a
gap they are meant to clear.

## 4. Nothing is stranded

Every room and every heart container is reachable in some state of the game;
`npm run verify:progression` asserts this separately and prints the gate
chain from a new game to the ending.
